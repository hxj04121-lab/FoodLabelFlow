# M3 本地前端操作与交接

## 本阶段可以演示的内容

技术栈为 React、TypeScript、Tailwind CSS、shadcn/ui。概览、供应商、物料、产品和配方采用明确标注的只读基线数据；系统状态页调用真实健康接口。页面中的本地预览身份不是登录凭据。

1. 打开产品目录，搜索产品名、品牌或 FDC 编号，切换分组和页码。
2. 点击产品，查看配方物料、对应规格、版本历史及数据来源。
3. 打开物料页面，查看供应商和规格组成。
4. 打开配方版本，点击“创建配方预览”。
5. 直接预览空表单，检查错误汇总和点击定位；填写产品、物料和对应规格后重试。
6. 添加第二项并删除，确认第一项输入保留；更换物料后必须重新选择规格。
7. 数量和单位可以留空。数量格式、数据库 DECIMAL(12,4) 容量及单位 40 字符限制在本地检查；不强制单位字典、100% 合计或重复物料规则。
8. 进入预览后返回编辑，检查内容仍保留。预览不会发起保存请求，也不生成正式版本号。
9. 输入后取消、按 Esc、点击遮罩或关闭按钮，会出现独立确认框。“继续编辑”保留输入；“放弃并关闭”清空。
10. 从其他页面进入配方页再编辑，使用浏览器后退，验证继续编辑或放弃后导航。刷新使用浏览器原生提示，移动设备强制结束进程不能保证触发提醒。

## 工程结构

- `frontend/src/App.tsx`：路由初始化。
- `frontend/src/app/Shell.tsx`：顶栏、导航、帮助及路由布局。
- `frontend/src/pages/`：概览、目录、物料、健康及未接入功能页。
- `frontend/src/features/catalog/`：产品表格与追溯详情。
- `frontend/src/components/FormulaCreator.tsx`：本地配方编辑与预览。
- `frontend/src/components/DiscardChangesDialog.tsx`：未保存确认 UI。
- `frontend/src/components/catalog-shared.tsx`：共享展示组件与基线导出。
- `frontend/src/data/catalog.ts`：基线类型与分组；`seed-preview.json` 是离线来源。
- `frontend/src/api/client.ts`：已存在的健康接口；未来业务接口应通过专用 adapter 接入，不在页面里直接操作数据库。

## 本地运行与测试

2026-09-08 独立工作验证：模块拆分后 TypeScript 检查、Vite 构建及 12 项 Playwright 浏览器测试通过。导入与代码格式已统一；页面数据与路由行为保留。构建有约 537 kB 主包体积提示，不影响运行，尚未做按路由拆包优化。

使用 Node 22.12 或更高的兼容版本，系统旧 Node 20.15 不满足当前 Vite 要求。在 frontend 目录运行 `npm ci`、`npm run dev`。构建为 `npm run build`，浏览器测试为 `npm run test:e2e`。默认使用已安装的 Microsoft Edge；其他平台需配置 Playwright 浏览器及 PLAYWRIGHT_CHANNEL。

测试覆盖只读浏览、筛选分页、导出、路由、窄屏、健康反馈、表单校验、字段联动、多行物料、选填值、键盘焦点、放弃提示和浏览器后退。健康成功/失败用明确的 HTTP 测试替身验证，不代表实时后端验收。测试截图在忽略的 `frontend/test-results/` 中。
