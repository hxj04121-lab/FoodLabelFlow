## Transaction structure

Before this change, run/result repositories had no shared application transaction entry point. The existing audit validation adapter already required `Propagation.MANDATORY`, but the repository round-trip was only called directly from a test transaction.

The final structure is:

```text
official M1 validation orchestration (not present; BLOCKED ON SCRUM-44)
  -> ValidationPersistenceService.persist (@Transactional)
  -> ValidationRunRepository.save
  -> ValidationResultRepository.saveAll
  -> ValidationIntegration.auditValidation
  -> AuditApplicationService.recordValidationEvent (MANDATORY)
  -> COMMIT

failure anywhere -> ROLLBACK ALL
```

No `REQUIRES_NEW` transaction is used. Persistence exceptions are not caught or converted to success.
