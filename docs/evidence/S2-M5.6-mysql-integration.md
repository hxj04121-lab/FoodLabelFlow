## M5 implementation retained

- `JdbcFormulaCompositionAdapter` implements catalog's official
  `FormulaCompositionPort`; catalog SQL remains inside the catalog owner adapter.
- `JdbcLabelSnapshotAdapter` implements label's official `LabelSnapshotPort`, uses
  `FormulaCompositionPort` for formula currentness, and returns the official
  `LabelValidationSnapshot` including declarations and current/stale semantics.
- `JdbcAllergenFactsAdapter` implements allergen's official `AllergenFactsPort`,
  queries only allergen-owned mappings, preserves derivation evidence and unresolved
  components, and consumes formula input only through the catalog snapshot.
- `RequestAuthorizationAdapter` implements the official `ValidationIntegration`
  bridge, resolves the trusted M4 actor, enforces `LABEL.VALIDATE`, and delegates
  same-transaction audit persistence through `AuditEventPort`.
- Existing `RuleSetVersionRepository`, `ValidationRunRepository` and
  `ValidationResultRepository` remain unchanged and are exercised by real MySQL.
- No Flyway migration was added; V1–V3 remain the canonical schema baseline.
